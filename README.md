# Квестпост — Ребут

Страница: https://maxcuso.github.io/questpost-reboot/

Автономная копия страницы обновления для GitHub Pages. PHP, Flarum, база данных и сборка не нужны. Все изображения, шрифты и значки находятся в этой папке.

## Где редактировать

- `index.html` — весь текст, даты и порядок блоков, с комментариями по разделам
- `style.css` — оформление страницы ребута
- `guide.css` — общие компоненты путеводителя и палитра обеих тем
- `icons.css` — используемые значки Font Awesome Free
- `page.js` — тема, типографика, пунктирная линия плана развития
- `assets/` — изображения и шрифты

Это отдельная копия: правки здесь не изменяют страницу расширения, а обновления расширения не перезаписывают эту папку автоматически.

## Публикация на GitHub Pages

1. Загрузите содержимое этой папки в корень отдельного репозитория, включая `assets` и `.nojekyll`.
2. В Settings → Pages выберите Deploy from a branch, ветку main и папку / (root).
3. Дождитесь публикации. Адрес будет вида https://maxcuso.github.io/questpost-reboot/.

Все пути к ресурсам относительные: страница работает и в корне домена, и в подпапке репозитория. Кнопки страницы показывают окошко «Скоро...» и не открывают сайт форума. Обработчик находится в конце `page.js`.

## Просмотр и тема

Для локального просмотра откройте `index.html` двойным щелчком. По умолчанию тема соответствует устройству. Для принудительной темы добавьте `?theme=light` или `?theme=dark` к адресу страницы.

## Вставка в тему форума

```html
<iframe src="https://maxcuso.github.io/questpost-reboot/" title="Квестпост — Ребут"
  style="display:block;width:100%;max-width:700px;height:850px;border:0;margin:0 auto"></iframe>
```

Максимальная ширина страницы — 700 px. При вставке с GitHub Pages форум и страница имеют разные домены: автоматическая высота и наследование темы родителя без отдельной настройки форума недоступны. Задайте нужную высоту iframe вручную, оставьте внутреннюю прокрутку или открывайте страницу отдельной ссылкой. Принудительную тему можно указать в src.
